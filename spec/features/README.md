# Feature Specs

One markdown file per feature. Use this template when creating a new spec.

---

## Template

Copy below into `spec/features/<feature-name>.md`:

```markdown
# Feature: <Title>

**Status:** Draft | Approved | Implemented  
**Author:** <name>  
**Created:** YYYY-MM-DD

## Summary

One paragraph describing the feature.

## User Stories

- As a <role>, I want <goal> so that <benefit>.

## Acceptance Criteria

- [ ] Criterion 1
- [ ] Criterion 2

## API Endpoints (if applicable)

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/... | ... |

## Data Model (if applicable)

| Field | Type | Notes |
|-------|------|-------|
| id | UUID | Primary key |

## Edge Cases

- What happens when ...?

## Out of Scope

- Item explicitly excluded from this feature

## Test Plan

- [ ] Unit tests for ...
- [ ] Integration test for ...

## Dependencies

- Requires: <other feature or none>
```
