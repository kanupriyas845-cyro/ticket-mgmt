# Plan Feature (Spec Only)

Plan a feature **without writing application code**.

## Steps

1. Ask the user for the feature name and brief description if not provided.
2. Read `spec/00-product-overview.md`, `spec/architecture.md`, and `spec/02-conventions.md`.
3. Check `spec/features/` for related or conflicting specs.
4. Draft a feature spec using the template in `spec/features/README.md`.
5. Save or propose the file at `spec/features/<feature-name>.md`.
6. Present the spec to the user and ask for approval before any implementation.

## Constraints

- Do **not** create backend or frontend code.
- Do **not** add dependencies or scaffold projects.
- Follow `docs/project-versions.md` when referencing the tech stack.
