# New Feature

Start a new feature using the spec-driven workflow.

## Steps

1. Confirm the feature name and goal with the user.
2. Follow the `spec-driven-workflow` skill to create `spec/features/<feature-name>.md`.
3. Include: user stories, acceptance criteria, API design, data model, edge cases, test plan, and out-of-scope items.
4. Present the spec for approval.
5. **Stop after spec approval.** Do not implement unless the user explicitly asks next.

## If User Wants Implementation

After approval, use the `implement-from-spec` skill and follow `rules/00-project-core.mdc`.
